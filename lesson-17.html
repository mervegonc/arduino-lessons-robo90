Bölüm 17: Arduino Const ve Define İfadeleri

Arduino projelerinde pin numaralarını veya sabit değerleri yönetirken doğrudan sayısal ifadeler kullanmak yerine isimler vermek kod okunabilirliğini artırır. Bu tanımlamaları yaparken standart değişkenler yerine const veya #define yapılarını kullarak bellek tasarrufu ve kod güvenliği sağlayabiliriz.

1. Sabit Tanımlama Yöntemleri Karşılaştırması

Projelerde sabit değerleri (örneğin pin numaralarını veya Pi sayısını) belirtmek için üç temel yaklaşım bulunur:

  • Normal Değişken (`int`): Değeri sonradan program içinde değiştirilebilir. Bellekte yer kaplar.
  • Sabit Değişken (`const`): Tanımlandıktan sonra değeri değiştirilemez (salt okunur). Bellekte yer kaplar ve hata denetimi sağlar.
  • Ön Derleyici Komutu (`#define`): Derleme aşamasında metin tabanlı olarak kodun içindeki ifadeleri doğrudan sayılarla değiştirir. Bellekte değişken için yer harcamaz.

2. Kod Örneği ve Kullanım Biçimleri

Aşağıdaki örnekte const int ve #define komutlarının kod içerisindeki kullanım kalıpları gösterilmiştir:

// #define Kullanımı (Noktalı virgül kullanılmaz, genellikle büyük harfle yazılır)
#define LED_BLUE 3
#define BUTON_PIN 8

// const int Kullanımı (Salt okunur sabit değişken)
const int LED_RED = 2;
int sayac = 0; // Normal, değeri değiştirilebilir değişken

void setup() {
  pinMode(LED_RED, OUTPUT);
  pinMode(LED_BLUE, OUTPUT);
  pinMode(BUTON_PIN, INPUT);
}

void loop() {
  // LED_RED = 5; -> HATA! const değişkenlerin değeri sonradan değiştirilemez.
  sayac++;      // Normal değişkenlerin değeri değiştirilebilir.
}

3. En İyi Uygulamalar ve İsimlendirme Kuralları

Yazılım geliştirme standartlarında, program boyunca değişmeyecek olan sabit tanımlamaların (pin numaraları, sabit katsayılar vb.) büyük harflerle yazılması önerilir. Bu sayede kodu inceleyen diğer geliştiriciler veya siz, hangi ifadenin sabit olduğunu hızlıca fark edebilirsiniz.
