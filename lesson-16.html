Bölüm 16: Arduino Dijital Pinlerini Çıkış Olarak Kullanmak

Arduino Uno üzerinde 0'dan 13'e kadar numaralandırılmış toplam 14 adet dijital pin bulunur. Bu pinler hem dijital giriş hem de dijital çıkış (digital write/read) işlemleri için kullanılabilir.

1. Arduino Uno Dijital Pin Yapısı ve Özel Pinler

  • PWM Pinleri (~): 3, 5, 6, 9, 10 ve 11 numaralı pinlerin yanında bulunan dalga işareti, bu pinlerin PWM (Darbe Genişlik Modülasyonu) çıkışı olarak da kullanılabileceğini gösterir.
  • TX ve RX Pinleri (0 ve 1): Haberleşme pinleridir. USB üzerinden bilgisayarla seri haberleşme yapılırken kullanılırlar. Kod yüklerken veya seri monitör kullanılırken bu pinlerin boşta olması önerilir; aksi takdirde bağlantılar iletişimi bozabilir.
  • Akım Sınırları: Pin başına maksimum 40 mA akım çekilebilir (tavsiye edilen güvenli sınır pin başı azami 20 mA, toplamda ise 200 mA'i geçmemektir).

2. Dijital Çıkış Komutları (`pinMode` ve `digitalWrite`)

Bir dijital pinden enerji çıkışı alabilmek (örneğin bir LED'i yakmak) için öncelikle pinMode fonksiyonu ile pinin modunu OUTPUT olarak ayarlamamız gerekir. Ardından digitalWrite fonksiyonu ile pini aktif (`HIGH`) veya pasif (`LOW`) duruma getirebiliriz.

  • HIGH (Lojik 1): Arduino Uno için 5 Volt çıkış gerilimi demektir.
  • LOW (Lojik 0): 0 Volt (Toprak / GND) demektir.
// Değişken tanımlamaları ile pin yönetimi (Kod okunabilirliğini artırır)
int ledRed = 2;
int ledBlue = 3;
int ledGreen = 4;
int ledYellow = 5;

void setup() {
  // Pinlerin çıkış olarak ayarlanması
  pinMode(ledRed, OUTPUT);
  pinMode(ledBlue, OUTPUT);
  pinMode(ledGreen, OUTPUT);
  pinMode(ledYellow, OUTPUT);
}

void loop() {
  // Tüm LED'leri yak
  digitalWrite(ledRed, HIGH);
  digitalWrite(ledBlue, HIGH);
  digitalWrite(ledGreen, HIGH);
  digitalWrite(ledYellow, HIGH);
  
  delay(1000); // 1 saniye bekle
  
  // Tüm LED'leri söndür
  digitalWrite(ledRed, LOW);
  digitalWrite(ledBlue, LOW);
  digitalWrite(ledGreen, LOW);
  digitalWrite(ledYellow, LOW);
  
  delay(1000); // 1 saniye bekle
}

3. En İyi Uygulamalar

Donanım bağlantılarında karmaşayı önlemek ve hangi pinin nereye bağlı olduğunu kolayca hatırlayabilmek için doğrudan sayısal pin numaraları yerine anlamlı değişken isimleri (örneğin ledGreen) kullanmak her zaman daha temiz bir yazılım yaklaşımıdır.
