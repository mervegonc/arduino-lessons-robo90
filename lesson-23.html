Arduino Eğitim Notları: Matematik & Zaman Yönetimi

Bu sayfada Robo90 Arduino Dersleri kapsamında işlenen Matematiksel Fonksiyonlar ve Delay Kullanmadan Zaman Yönetimi (millis) konuları özetlenmiştir.

1. Matematiksel Fonksiyonlar (Lesson-22)

Öne Çıkan Komutlar

  • sq() / square(): Verilen parametrenin karesini alır.
  • sqrt(): Karekök alır. Geriye hassasiyet nedeniyle Double türünde değer döndürür.
  • pow(taban, us): Üs alma işlemi yapar.
  • min() / max(): İki sayı arasında küçük veya büyük olanı seçer.
  • abs(): Mutlak değer hesaplar.
  • constrain(deger, min, max): Bir değeri belirli sınırlar arasında sabitler; dışındaysa sınırlara çeker.
  • map(deger, min1, max1, min2, max2): Bir aralıktaki veriyi orantılı olarak başka bir aralığa dönüştürür (Örn: Potansiyometreyi servo açıya çevirme).

2. Delay Kullanmadan Bekleme Yapmak (Lesson-32)

Neden millis() Kullanmalıyız?

delay() komutu çalışırken Arduino'yu tamamen durdurur (bloklar). Bu durum, arka planda basılan butonların veya sensör verilerinin kaçırılmasına yol açar. millis() fonksiyonu ile kod bloklanmadan aynı anda birden fazla iş yürütülebilir.

unsigned long eskiZaman = 0;
const long beklemeSuresi = 1000; // 1 saniye

void loop() {
  unsigned long simdikiZaman = millis();

  // 1 saniye geçip geçmediğini kontrol et
  if (simdikiZaman - eskiZaman >= beklemeSuresi) {
    eskiZaman = simdikiZaman;
    // Zamanı gelen işlemler burada yapılır (Örn: LED durumunu değiştir)
  }

  // Bu sayede buton okuma gibi işlemler hiç gecikmeden anında çalışır
  digitalRead(3); 
}

Özet Karşılaştırma

Konu Temel Araçlar Avantajı
Matematiksel İşlemler map(), constrain(), pow() vb. Karmaşık hesaplamaları ve sensör-aktüatör kalibrasyonlarını kolaylaştırır.
Zaman Yönetimi millis(), unsigned long Programın kilitlenmesini önler, eş zamanlı (non-blocking) görev yönetimini sağlar.
