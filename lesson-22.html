Arduino Temel Matematiksel Fonksiyonlar

Bu sayfada, Arduino programlama dilinde kod yükünü hafifleten ve sıkça kullanılan temel matematik fonksiyonları yer almaktadır.

1. Square (`square` / `sq`)

Kendisine verilen parametrenin karesini geri döndürür.

int a = 5;
int sonuc = sq(a); // Sonuç: 25

2. Square Root (`sqrt`)

Bir sayının karekökünü alır. Geriye hassasiyet gereği Double (Arduino'da genellikle float ile aynı) veri tipinde değer döndürür.

int sayi = 144;
double sonuc = sqrt(sayi); // Sonuç: 12.00

3. Power (`pow`)

Üs alma işlemidir. İki parametre alır: birinci parametre taban, ikincisi üüstür. Sonucu Double türünde döndürür.

// 5 üzeri 2 hesabı
double sonuc = pow(5, 2); // Sonuç: 25.00

4. Min & Max (`min`, `max`)

`min()`: Verilen iki parametreden daha küçük olanı seçer.
`max()`: Verilen iki parametreden daha büyük olanı seçer.

int kucuk = min(5, 2); // Sonuç: 2

5. Absolute Value (`abs`)

Bir sayının mutlak değerini hesaplar. Negatif sayıları pozitif yapar.

int sonuc = abs(-851); // Sonuç: 851

6. Constrain (`constrain`)

Bir değeri belirli bir alt ve üst sınır arasında tutmak için kullanılır. Değer aralığın dışındaysa en yakın sınıra çekilir. Üç parametre alır: (deger, min, max).

// Değer 5 ama sınırlar 10 ile 150. Sonuç min sınır olan 10 olur.
int sinirliDeger = constrain(5, 10, 150);

7. Map (`map`)

Bir aralıktaki veriyi başka bir aralığa orantılı (lineer) bir şekilde dönüştürür. Beş parametre alır: (deger, min_girdi, max_girdi, min_cikti, max_cikti).

// Potansiyometreden gelen 0-1023 arasını, servo motor için 0-180 arasına çevirir
int servoAci = map(potDegeri, 0, 1023, 0, 180);
