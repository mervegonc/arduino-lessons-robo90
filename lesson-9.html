Bölüm 9: Karşılaştırma ve Mantık Operatörleri

Kontrol yapılarına (şartlı ifadeler ve döngüler) geçmeden önce, programlama hayatın boyunca en sık kullanacağın temellerden biri olan karşılaştırma ve mantık operatörlerini inceleyeceğiz. Bu operatörlerin sonuçları Arduino'da mantıksal olarak doğru ise 1 (True), yanlış ise 0 (False) değerini döndürür. Sonuçları test etmek için seri monitörden faydalanacağız.

1. Karşılaştırma Operatörleri

İki değer arasındaki ilişkiyi sorgulamamızı sağlayan 6 temel karşılaştırma operatörümüz bulunur:

  • Küçüktür (<): Sol taraftaki değer sağdakinden küçük mü? (Örn: 5 < 10 → 1 / True)
  • Büyüktür (>): Sol taraftaki değer sağdakinden büyük mü? (Örn: 5 > 10 → 0 / False)
  • Küçük Eşit (<=): Sol taraftaki değer sağdakinden küçük veya eşit mi?
  • Büyük Eşit (>=): Sol taraftaki değer sağdakinden büyük veya eşit mi?
  • Eşittir (==): İki değer birbirine eşit mi? Dikkat: Tek eşittir (=) atama operatörüdür; karşılaştırma için mutlaka çift eşittir (==) kullanılmalıdır.
  • Eşit Değildir (!=): İki değer birbirine eşit değil mi?
int a = 5;
int b = 10;

void setup() {
  Serial.begin(9600);
  
  // Örnek Karşılaştırmalar
  Serial.println(a < b);  // Çıktı: 1 (True) çünkü 5, 10'dan küçüktür
  Serial.println(a == b); // Çıktı: 0 (False) çünkü 5, 10'a eşit değildir
}

void loop() {
  // Döngü boş
}

2. Mantık Operatörleri

Birden fazla koşulu birleştirmek veya mevcut bir koşulun sonucunu tersine çevirmek için mantık operatörleri kullanılır.

  • VE Operatörü (&&): İşleme sokulan koşulların tamamının doğru (1) olması gerekir. Hepsi doğruysa sonuç 1, aksi halde 0'dır. (Günlük hayattaki "Marketten hem cips hem kola al" komutu gibidir; ikisi de alınmazsa sonuç başarısızdır).
  • VEYA Operatörü (||): Koşullardan en az birinin doğru (1) olması sonuç için yeterlidir. Hepsibiri yanlışsa sonuç 0 olur. (Günlük hayattaki "Cips veya bisküvi al" komutu gibidir; ikisinden birinin alınması yeterlidir).
  • DEĞİL Operatörü (!): İşleme giren koşulun sonucunun tam tersini alır (True'yu False, False'u True yapar).
int a = 5;
int b = 10;
int c = 13;

void setup() {
  Serial.begin(9600);

  // Mantıksal VE Örneği (False ve True -> False)
  Serial.println((a < b) && (a > c)); // Çıktı: 0

  // Mantıksal VEYA Örneği (False veya True -> True)
  Serial.println((a > b) || (c > b)); // Çıktı: 1

  // Mantıksal DEĞİL Örneği
  Serial.println(!(a == b));          // Çıktı: 1 (a b'ye eşit değildir ifadesi doğru olduğu için tersi 1 olur)
}

void loop() {
}

3. Kod İpucu: Kodları Hizalama

Karmaşık ve uzun mantıksal sorgular yazdığında kodun okunabilirliği azalabilir. Arduino IDE üzerinde Ctrl + T (Mac için Cmd + T) tuş kombinasyonunu kullanarak kodlarını otomatik olarak hizalayabilir ve düzenli bir görünüme kavuşturabilirsin.
