Bölüm 18: Arduino ile Analog Giriş İşlemleri

Arduino Uno üzerinde dış dünyadaki sürekli değişen sinyalleri (sıcaklık, ışık, potansiyometre konumu vb.) okuyabilmek için A0 ile A5 arasında etiketlenmiş 6 adet analog giriş pini bulunur. Bu bölümde analog sinyallerin dijital verilere dönüştürülme sürecini inceleyeceğiz.

1. ADC (Analog-Digital Converter) ve Çözünürlük Mantığı

  • Analog Okuma Komutu: Bir analog pinden değer okumak için analogRead(pinAdi) fonksiyonu kullanılır (Örn: analogRead(A0)).
  • 10-Bit Çözünürlük: Arduino Uno'daki analog dönüştürücü (ADC) 10-bitliktir. Bu da $2^{10} = 1024$ farklı değer anlamına gelir.
  • Değer Aralığı: Analog pinden okunan değerler 0 ile 1023 arasındadır (0 dahil, toplam 1024 kademe).
  • Ölçüm Hassasiyeti: Arduino 5 Volt ile çalıştığı için, 5000 mV'luk gerilim 1023 parçaya bölünür. Bu durum yaklaşık 4.88 mV hassasiyetle okuma yapabileceğimiz anlamına gelir.

2. Kod Örneği: Potansiyometre Okuma ve Voltaj Hesaplama

Aşağıdaki örnekte potansiyometreden gelen ham değer okunur ve bu değer matematiksel işlemlerle milivolt/volt cinsine dönüştürülerek Seri Monitöre yazdırılır:

int potPin = A0;   // Potansiyometrenin bağlı olduğu analog pin
int deger = 0;     // Ham veriyi saklayacak değişken
float voltaj = 0.0;// Hesaplanan gerilim değeri

void setup() {
  Serial.begin(9600); // Seri haberleşmeyi başlat
}

void loop() {
  // A0 pininden 0 - 1023 arasında ham değer oku
  deger = analogRead(potPin);

  // Ham değeri milivolta çevir (Float hassasiyeti için 5000.0 kullanıldı)
  voltaj = (deger * 5000.0) / 1023.0;

  // Sonuçları Seri Monitöre yazdır
  Serial.print("Ham Deger: ");
  Serial.print(deger);
  Serial.print(" | Voltaj: ");
  Serial.print(voltaj);
  Serial.println(" mV");

  delay(500); // Yarım saniye bekle
}

3. Önemli İpuçları

Analog sensörlerden gelen ham 0-1023 verileri tek başına fiziksel bir anlam ifade etmez. Projelerinizde anlamlı sonuçlar elde edebilmek için bu ham verileri yukarıdaki örnekte olduğu gibi orantılayarak voltaja veya sıcaklık/mesafe gibi gerçek dünya birimlerine dönüştürmeniz gerekir.
