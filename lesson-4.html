Bölüm 4: Dijital Pinler, pinMode, digitalWrite ve digitalRead

Arduino dünyasında fiziksel çevreyle etkileşime geçmenin, sensörlerden veri okumanın ve çevre birimlerini kontrol etmenin temel yolu Dijital Pinlerdir. Bu bölümde dijital pinlerin mantığını ve temel fonksiyonlarını inceleyeceğiz.

1. Dijital Pin Nedir ve Lojik Seviyeler (HIGH / LOW)

Arduino kartları üzerinde (örneğin Uno modelinde) 0 ile 13 arasında numaralandırılmış dijital giriş/çıkış pinleri bulunur. Dijital mantık ikili (binary) sisteme dayanır:

  • HIGH (Lojik 1 / 5V): Pinde elektrik akımının olduğunu, voltajın tepe noktada (+5V) olduğunu ifade eder.
  • LOW (Lojik 0 / 0V): Pinde gerilim olmadığını, pinin toprak (GND) seviyesinde olduğunu ifade eder.

2. Pin Yönünü Belirleme: pinMode() Fonksiyonu

Bir dijital pini kullanmadan önce Arduino'ya o pinin giriş mi yoksa çıkış mı olacağını söylememiz gerekir. Bu tanımlama setup() fonksiyonu içerisinde pinMode() komutu ile yapılır.

Kullanımı: pinMode(pinNumarasi, Mod);

  • OUTPUT (Çıkış): Pinden dışarıya elektrik enerjisi göndermek (LED yakmak, motor sürmek vb.) için kullanılır.
  • INPUT (Giriş): Dışarıdan pin aracılığıyla veri okumak (Buton durumu, sensör sinyali vb.) için kullanılır.

3. Çıkış Kontrolü: digitalWrite() Fonksiyonu

Eğer bir pin OUTPUT olarak tanımlandıysa, o pine HIGH veya LOW sinyali vererek akış sağlamak veya kesmek için digitalWrite() fonksiyonu kullanılır.

void setup() {
  pinMode(8, OUTPUT); // 8 numaralı pini çıkış olarak ayarladık
}

void loop() {
  digitalWrite(8, HIGH); // 8 numaralı pine +5V gönderir (LED yanar)
  delay(1000);           // 1 saniye bekler
  digitalWrite(8, LOW);  // 8 numaralı pini 0V yapar (LED söner)
  delay(1000);           // 1 saniye bekler
}

4. Veri Okuma: digitalRead() Fonksiyonu

Eğer bir pin INPUT olarak tanımlandıysa, o pine bağlı olan elemanın (örneğin bir butonun) basılı olup olmadığını veya lojik durumunu okumak için digitalRead() fonksiyonu kullanılır.

int butonPin = 7;
int durum = 0;

void setup() {
  pinMode(butonPin, INPUT); // 7 numaralı pini giriş olarak ayarladık
  Serial.begin(9600);       // Seri haberleşmeyi başlattık
}

void loop() {
  durum = digitalRead(butonPin); // 7 numaralı pindeki lojik durumu okur (HIGH veya LOW)
  Serial.println(durum);         // Okunan değeri ekrana yazdırır
}

5. Özet ve Donanım Mantığı

  • Aktüatörler (Çıkışlar): LED, buzzer ve motorlar genellikle OUTPUT ve digitalWrite() ile yönetilir.
  • Sensörler / Butonlar (Girişler): Düğmeler ve dijital sensörler dış dünyadan gelen veriyi INPUT ve digitalRead() ile karta aktarır.
