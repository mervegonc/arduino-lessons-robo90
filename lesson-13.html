Bölüm 13: break ve continue İfadeleri

Döngüler, belirtilen koşullar altında istenen komutları tekrarlı bir şekilde çalıştırır. Ancak bazı durumlarda döngü akışına dışarıdan müdahale etmek ve döngüyü manipüle etmek gerekebilir. Bu gibi senaryolarda break ve continue ifadeleri kullanılır.

1. break İfadesi ve Kullanımı

break komutu, döngünün normal şartlar altında tamamlanmasını beklemeden, herhangi bir koşul gerçekleştiğinde anında döngüden çıkılmasını (döngünün kırılmasını) sağlar. Bu yapı, hem while hem de for döngüleriyle birlikte kullanılabilir.

void setup() {
  Serial.begin(9600);
  int i = 0;

  while (i < 10) {
    // i değeri 4 olduğunda döngü kırılacak
    if (i == 4) {
      break; 
    }
    
    Serial.println(i);
    i++;
  }
}

void loop() {
}

2. continue İfadesi ve Çalışma Mantığı

continue komutu, döngü içerisindeki o anki turda kalan işlemlerin pas geçilmesini ve doğrudan döngünün başına dönülerek sonraki turdan devam edilmesini sağlar. Belirli bir koşul sağlandığında döngünün geri kalan kodlarını çalıştırmadan es geçmek için oldukça pratiktir.

void setup() {
  Serial.begin(9600);

  for (int i = 0; i < 5; i++) {
    // i değeri 2 olduğunda bu tur pas geçilir
    if (i == 2) {
      continue; 
    }
    
    Serial.print("Döngü Adimi: ");
    Serial.println(i);
  }
}

void loop() {
}

3. Özet ve Dikkat Edilmesi Gerekenler

  • break: Koşul sağlandığı anda döngüyü tamamen sonlandırır ve döngü dışındaki satırlardan akışa devam eder.
  • continue: Sadece o anki turu yarıda keser, döngüyü bitirmez; bir sonraki adımdan (turdan) döngüyü döndürmeye devam eder.
