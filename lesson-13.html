Bölüm 13: Şartlı İfadeler (if-else if-else)

Programlama dünyasında akış kontrolü sağlamanın temel taşı şartlı ifadelerdir. Bu yapılar, belirli koşulların doğru (True) veya yanlış (False) olmasına göre programın farklı yollardan ilerlemesine olanak tanır.

1. if Yapısı ve Mantığı

if yapısı, parantez içindeki koşul sağlandığında (True döndüğünde) kendisine bağlı olan kod bloğunu çalıştırır. Koşul sağlanmazsa (False), program bu bloğu tamamen atlar.

int notDegeri = 85;

if (notDegeri >= 60) {
  Serial.println("Gectiniz");
}

2. else ile Alternatif Yol

else komutu, if şartının sağlanmadığı tüm durumlarda otomatik olarak çalışır. Bir şartın tam tersini belirtmek için kullanılır ve herhangi bir parantez/koşul gerektirmez. İşlemci gücünden tasarruf sağlar çünkü if şartı sağlandığında else kısmına hiç bakılmaz.

3. else if ile Çoklu Sorgulama

İkiden fazla seçenek olduğunda else if yapısı devreye girer. Bu yapı, birbirine bağlı alternatif koşulları sırasıyla kontrol etmemizi sağlar.

if (notDegeri >= 60) {
  Serial.println("Gectiniz");
} else if (notDegeri >= 40) {
  Serial.println("Sinava tekrar girebilirsiniz");
} else {
  Serial.println("Kaldiniz");
}

4. Önemli İpuçları ve Hatalar

  • Süslü Parantez ({ }): Kontrol yapılarınız ne kadar kısa olursa olsun, kod okunabilirliğini ve yönetilebilirliğini artırmak için süslü parantez kullanmayı standart haline getirin.
  • Sıralama Hatası: Çoklu sorgulamalarda en dar kapsamlı veya öncelikli şartları yukarıya yazmak mantık hatalarını (bug) önler.
  • Değişken İsimleri: Arduino'nun kendi komutlarıyla (örneğin int note gibi) çakışan isimleri değişken olarak kullanmaktan kaçının; büyük-küçük harf duyarlılığına dikkat edin.
