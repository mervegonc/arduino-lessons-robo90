Bölüm 14: While ve Do-While Döngüleri

Yazılımda belirli bir koşulun doğruluğuna bağlı olarak işlemlerin tekrarlanmasını sağlayan kontrol yapılarından biri while döngüsüdür. Koşul sağlandığı sürece blok içerisindeki kodlar çalışmaya devam eder.

1. While Döngüsünün Yapısı ve Çalışma Mantığı

while döngüsü, parantez içerisindeki şartın (True) kontrolüyle başlar. Sayacın döngü dışında tanımlanması ve döngü içerisinde mutlaka güncellenmesi gerekir, aksi takdirde program sonsuz döngüye girer.

void setup() {
  Serial.begin(9600);

  int sayac = 0;
  
  // sayac 5'ten küçük olduğu sürece çalışır
  while (sayac < 5) {
    Serial.println(sayac);
    sayac++; // Değer artırılmazsa sonsuz döngü oluşur
  }
}

void loop() {
}

2. Do-While Döngüsü

Normal while döngüsünde koşul baştan kontrol edilir; eğer şart başlangıçta yanlışsa döngü hiç çalışmaz. Ancak do-while döngüsünde blok koşula bakılmaksızın en az bir kez mutlaka çalıştırılır, koşul kontrolü ise döngünün sonunda yapılır.

void setup() {
  Serial.begin(9600);

  int sayaci = 10;

  do {
    Serial.println(sayaci);
    sayaci++;
  } while (sayaci < 5); // Şart yanlış olsa bile blok en az 1 kez çalışmıştır
}

void loop() {
}

3. Kullanım Alanları ve Dikkat Edilmesi Gerekenler

  • Sonsuz Döngü Riski: Sayaç artırımı veya koşulu değiştirecek parametre unutulursa mikrodenetleyici kilitlenebilir.
  • Sensör ve Seri Port Beklemeleri: Belirli bir dış koşul oluşana kadar (örneğin butona basılana ya da seri porttan veri gelene kadar) programı bekletmek için sıklıkla tercih edilir.
