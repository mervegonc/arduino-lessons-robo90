Switch-Case Kullanımı ve If-Else Farkı - Robo90 #28

Giriş ve Temel Problem Senaryosu

Programlamada kontrol yapılarının önemli bir üyesi olan Switch-Case yapısı [cite: xznDQX-hENA], bir değişkenin alabileceği farklı sabit değerleri ayrı ayrı incelemek ve programın akışına yön vermek amacıyla kullanılır [cite: xznDQX-hENA]. Konuyu en iyi şekilde kavramak için pratik bir senaryo ele alınmıştır: Kendisine verilen ay numarasına göre (1-12 arası) o ayın kaç gün çektiğini ekrana yazdıran bir program geliştirmek [cite: xznDQX-hENA].

  • Ocak, Mart, Mayıs, Temmuz, Ağustos, Ekim, Aralık: 31 gün çeker.
  • Nisan, Haziran, Eylül, Kasım: 30 gün çeker.
  • Şubat: Normal yıllarda 28, artık yıllarda 29 gün çeker.

If-Else Yapısı ile Çözüm

Benzer bir problemi çözmek için ilk olarak aşina olduğumuz if-else ve else if yapıları kullanılabilir. Aşağıdaki örnek kod bloğu bu mantığı temel almaktadır [cite: xznDQX-hENA]:

int ay = 7; // Örnek olarak Temmuz ayı seçildi

void setup() {
  Serial.begin(9600);
}

void loop() {
  if (ay == 1 || ay == 3 || ay == 5 || ay == 7 || ay == 8 || ay == 10 || ay == 12) {
    Serial.println("31 gün çeker");
  } 
  else if (ay == 4 || ay == 6 || ay == 9 || ay == 11) {
    Serial.println("30 gün çeker");
  } 
  else if (ay == 2) {
    Serial.println("28 ya da 29 gün çeker");
  } 
  else {
    Serial.println("Hata: Ay sadece 1 ile 12 arasında olabilir!");
  }
  
  delay(5000);
}

Switch-Case Yapısı ile Temel Kullanım

Aynı senaryo Switch-Case yapısı kullanılarak her ay için ayrı bir case bloğu oluşturulacak şekilde şu şekilde yazılabilir [cite: xznDQX-hENA]:

  • switch(degisken): Kontrol edilecek değişken parantez içine yazılır [cite: xznDQX-hENA].
  • case Değer: Değişkenin o anki eşleşebileceği sabit durumları ifade eder [cite: xznDQX-hENA].
  • break: İlgili durumun çalışması bittikten sonra switch-case bloğundan çıkılmasını sağlar. Eğer break unutulursa akış bir sonraki case bloğuna akmaya (fall-through) devam eder [cite: xznDQX-hENA].
  • default: Belirtilen case durumlarının hiçbirine uymayan (else karşılığı olan) durumları yakalar [cite: xznDQX-hENA].
int ay = 7;

void setup() {
  Serial.begin(9600);
}

void loop() {
  switch (ay) {
    case 1:
      Serial.println("Ocak: 31 gün çeker");
      break;
    case 2:
      Serial.println("Şubat: 28 ya da 29 gün çeker");
      break;
    case 3:
      Serial.println("Mart: 31 gün çeker");
      break;
    case 4:
      Serial.println("Nisan: 30 gün çeker");
      break;
    case 5:
      Serial.println("Mayıs: 31 gün çeker");
      break;
    case 6:
      Serial.println("Haziran: 30 gün çeker");
      break;
    case 7:
      Serial.println("Temmuz: 31 gün çeker");
      break;
    case 8:
      Serial.println("Ağustos: 31 gün çeker");
      break;
    case 9:
      Serial.println("Eylül: 30 gün çeker");
      break;
    case 10:
      Serial.println("Ekim: 31 gün çeker");
      break;
    case 11:
      Serial.println("Kasım: 30 gün çeker");
      break;
    case 12:
      Serial.println("Aralık: 31 gün çeker");
      break;
    default:
      Serial.println("Hata: Ay sadece 1 ile 12 arasında olabilir!");
      break;
  }
  
  delay(5000);
}

Case Gruplandırma (Optimizasyon) Tekniği

Switch-case yapısının en büyük avantajlarından biri, birden fazla case durumunun ortak bir sonucu paylaştığı durumlarda araya break koymayarak kodun alt alta gruplandırılabilmesidir. Bu sayede kod daha temiz ve okunabilir hale gelir [cite: xznDQX-hENA]:

int ay = 7;

void setup() {
  Serial.begin(9600);
}

void loop() {
  switch (ay) {
    case 1:
    case 3:
    case 5:
    case 7:
    case 8:
    case 10:
    case 12:
      Serial.println("31 gün çeker");
      break;
      
    case 4:
    case 6:
    case 9:
    case 11:
      Serial.println("30 gün çeker");
      break;
      
    case 2:
      Serial.println("28 ya da 29 gün çeker");
      break;
      
    default:
      Serial.println("Hata: Ay değeri 1-12 arasında olmalıdır!");
      break;
  }
  
  delay(5000);
}

If-Else ve Switch-Case Karşılaştırması

  • If-Else Yapısı: Mantıksal aralıklar (örneğin x > 5 && x < 10), koşullu ifadeler ve karmaşık boolean kıyaslamaları için çok daha uygundur [cite: xznDQX-hENA].
  • Switch-Case Yapısı: Tek bir değişkenin farklı sabit değerlerle (1, 2, 'A', 'B' vb.) eşleştirilmesi gerektiği durumlarda kod okunabilirliğini artırır ve derleme aşamasında optimizasyon avantajı sağlar [cite: xznDQX-hENA].
  • Performans Notu: Yapıların mikrodenetleyici üzerindeki çalışma hızı farkı, küçük ölçekli hobi ve Arduino projelerinde insan gözüyle fark edilebilecek düzeyde bir değişiklik yaratmaz; seçim genellikle kodun okunabilirliğine ve geliştirme kolaylığına göre yapılır [cite: xznDQX-hENA].
