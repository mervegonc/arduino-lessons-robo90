Bölüm 19: Arduino Analog Çıkış İşlemleri ve PWM Tekniği

Arduino Uno üzerinde donanımsal bir DAC (Dijital-Analog Dönüştürücü) bulunmadığı için doğrudan ara gerilim değerlerinde analog çıkış üretilemez. Ancak kontrol uygulamalarında analog etki elde edebilmek için PWM (Darbe Genişlik Modülasyonu) adı verilen özel bir teknik kullanılır.

1. PWM (Pulse Width Modulation) Nedir?

  • Çalışma Prensibi: Dijital pinlerin çok yüksek frekansta hızla açılıp kapatılması (HIGH/LOW yapılması) suretiyle ortalama bir gerilim etkisi yaratılmasıdır. Gözümüz veya bağlı olan cihaz (motor, LED vb.) bu hızlı değişimleri yakalayamaz ve ortalama değeri hisseder.
  • PWM Destekli Pinler: Arduino Uno üzerinde yanında tilde işareti (`~`) bulunan pinler PWM çıkışı destekler: 3, 5, 6, 9, 10 ve 11 numaralı pinler.
  • Değer Aralığı (`analogWrite`): PWM çıkışı vermek için analogWrite(pin, deger) fonksiyonu kullanılır. Buradaki değer 0 ile 255 arasındadır:
    • 0: %0 Doluluk Oranı (0 Volt / Tamamen Kapalı)
    • 127: %50 Doluluk Oranı (Yaklaşık 2.5 Volt / Yarı Parlaklık)
    • 255: %100 Doluluk Oranı (5 Volt / Tam Parlaklık)

2. Kod Örneği: LED Parlaklığını Kademeli Değiştirme (Fading)

Aşağıdaki örnekte PWM kullanılarak bir LED'in parlaklığı yavaş yavaş artırılmakta ve ardından azaltılmaktadır:

int ledPin = 9; // PWM destekli pin

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  // Parlaklığı yavaş yavaş artır (0'dan 255'e)
  for (int parlaklik = 0; parlaklik <= 255; parlaklik++) {
    analogWrite(ledPin, parlaklik);
    delay(10); // Her adımda 10 milisaniye bekle
  }

  // Parlaklığı yavaş yavaş azalt (255'ten 0'a)
  for (int parlaklik = 255; parlaklik >= 0; parlaklik--) {
    analogWrite(ledPin, parlaklik);
    delay(10); // Her adımda 10 milisaniye bekle
  }
}

3. Kullanım Alanları

PWM tekniği yalnızca LED parlaklık kontrolünde değil; aynı zamanda DC motorların hız kontrolünde, hobi servolarının konumlandırılmasında ve buzzer ile ses/frekans üretiminde yaygın olarak kullanılmaktadır.
