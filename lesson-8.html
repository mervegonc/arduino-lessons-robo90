Bölüm 8: Temel Matematik İşlemleri

Arduino projeleri geliştirirken karmaşık matematiksel işlemlerden korkmanıza gerek yoktur. Hazır kütüphaneler ve temel operatörler sayesinde matematiksel yükü minimuma indirebilirsiniz.

1. Temel Matematik Operatörleri ve Atama Mantığı

Arduino'da en sık kullanılan 6 temel operatör bulunur: Atama (=), Toplama (+), Çıkartma (-), Çarpma (*), Bölme (/) ve Mod/Kalan (%).

  • Atama Operatörü (=): Matematikteki "eşittir" anlamından farklıdır. Sağdaki değeri alır, soldaki değişkenin üzerine kaydeder. Örn: a = a + 3;
  • Mod Operatörü (%): Bir sayının diğerine bölümünden kalanı verir. Örn: 13 % 5 = 3

2. Bölme İşlemi ve Veri Tipleri (int vs float)

Tam sayı (int) türündeki iki değişken birbirine bölündüğünde sonuç küsuratlı olsa bile tam sayı döner. Ondalıklı hassas sonuçlar için değişken float tanımlanmalı ve sayılardan biri ondalıklı (örneğin 12.0) verilmelidir:

int a = 12;
int b = 5;
float c;

void setup() {
  Serial.begin(9600);
  c = (float)a / b; // Hassas sonuç için float dönüşümü
  Serial.println(c); // Çıktı: 2.40
}

void loop() {
}

3. İşlem Önceliği ve Bileşik Operatörler

İşlem sırası önce iç parantez, sonra çarpma/bölme/mod, en son toplama/çıkarma şeklinde ilerler. Ayrıca uzun ifadeleri kısaltmak için bileşik operatörler (ör. sayac++) kullanılır.

int sayac = 0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  sayac++; // Değeri sürekli 1 artırır
  Serial.println(sayac);
  delay(1000);
}
