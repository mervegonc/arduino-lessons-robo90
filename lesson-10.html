Bölüm 10: Şartlı İfadeler (if-else if-else)

Şartlı ifadeler, programınızın akışını kontrol etmenize imkan tanıyan ve programlama hayatınız boyunca en çok kullanacağınız komutlardır. Önceki bölümlerde öğrendiğimiz karşılaştırma ve mantık operatörlerini bu yapılarla birleştirerek kararlar alan akıllı programlar yazabiliriz.

1. Temel if Yapısı

Bir koşulun doğru (1 / True) olması durumunda belirli kod bloklarının çalıştırılmasını sağlar. Eğer koşul yanlışsa, if bloğunun içi atlanır.

int sinavNotu = 85;

void setup() {
  Serial.begin(9600);
  
  // Eğer not 60'tan büyük veya eşitse
  if (sinavNotu >= 60) {
    Serial.println("Tebrikler, dersi geçtiniz!");
  }
}

void loop() {
  // Döngü boş
}

2. else ve else if Kullanımı

Birden fazla alternatif durumu kontrol etmek ve ilk koşul sağlanmadığında devreye girecek alternatifler üretmek için else ve else if yapıları kullanılır:

  • else: Kendisinden önceki if veya else if koşullarının hiçbiri sağlanmadığı tüm diğer durumlarda otomatik olarak çalışır. Ek bir koşul parantezi almaz.
  • else if: İlk koşul tutmadığında yeni ve farklı bir koşul daha test etmek istiyorsak kullanılır.
int sinavNotu = 45;

void setup() {
  Serial.begin(9600);

  if (sinavNotu >= 60) {
    Serial.println("Geçtiniz!");
  } 
  else if (sinavNotu >= 40) {
    Serial.println("Sınava tekrar girme hakkı kazandınız.");
  } 
  else {
    Serial.println("Maalesef dersten kaldınız.");
  }
}

void loop() {
}

3. Sık Yapılan Hatalar ve Altın Kurallar

  • Değişken İsmi Çakışması: Arduino IDE içerisinde sistem tarafından önceden tanımlanmış rezerve kelimeleri (örneğin note vb.) değişken ismi olarak kullanmaktan kaçının. Harf duyarlılığına dikkat edin.
  • Süslü Parantez ({ }) Kullanımı: Koşula bağlı çalıştırılacak kod tek satır olsa bile süslü parantez kullanmayı alışkanlık haline getirin. Parantez eksikliği, kod akışında mantıksal hatalara (bug) yol açabilir.
  • Sıralama Mantığı: Çoklu else if yapıları kullanırken koşulların büyüklük/küçüklük öncelik sıralamasına dikkat edin. Yanlış sıralama, mikrodenetleyicinin yanlış koşulu erken yakalamasına neden olabilir.
  • İşlemci Verimliliği: Birbiriyle ilişkili durumlarda bağımsız ayrı if blokları yazmak yerine if - else if - else zinciri kurmak, mikrodenetleyicinin gereksiz yere yorulmasını engeller ve işlemci gücünden tasarruf sağlar.
