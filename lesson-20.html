Arduino ve LED'ler ile Antrenman (1. Örnek) - Robo90 #23

Devre Kurulumu ve Donanım Detayları

Bu uygulamada breadboard üzerine 5 farklı renkte LED yerleştirilmiştir. LED'lerin kısa bacakları (katot) ortak bir hat üzerinden Arduino'nun GND pinine bağlanırken, uzun bacakları (anot) sırasıyla dijital pinlere yönlendirilmiştir.

  • Bağlantı Pinleri: Dijital 2, 3, 4, 5 ve 6 numaralı pinler.
  • Amaç: Döngüler ve temel komutlar yardımıyla LED'ler üzerinde farklı yakma animasyonları gerçekleştirmek.

1. Uygulama: Tüm LED'leri Aynı Anda Yakıp Söndürme

Temel seviyede tüm dijital pinleri çıkış (OUTPUT) olarak ayarlayıp, aynı anda HIGH ve LOW komutlarıyla bütün LED'lerin beraber çalışması sağlanmıştır.

void setup() {
  pinMode(2, OUTPUT);
  pinMode(3, OUTPUT);
  pinMode(4, OUTPUT);
  pinMode(5, OUTPUT);
  pinMode(6, OUTPUT);
}

void loop() {
  // Tüm LED'leri Aç
  digitalWrite(2, HIGH);
  digitalWrite(3, HIGH);
  digitalWrite(4, HIGH);
  digitalWrite(5, HIGH);
  digitalWrite(6, HIGH);
  delay(1000);

  // Tüm LED'leri Kapat
  digitalWrite(2, LOW);
  digitalWrite(3, LOW);
  digitalWrite(4, LOW);
  digitalWrite(5, LOW);
  digitalWrite(6, LOW);
  delay(1000);
}

2. Uygulama: For Döngüsü ile Sıralı Tarama

Kod kalabalığından kaçınmak ve pratiklik kazanmak adına for döngüleri kullanılarak önce 2'den 6'ya doğru artan, ardından 6'dan 2'ye doğru azalan sıralı bir akış kurulmuştur.

void loop() {
  // 2'den 6'ya doğru sırayla yak
  for (int i = 2; i <= 6; i++) {
    digitalWrite(i, HIGH);
    delay(500);
  }
  
  // 6'dan 2'ye doğru sırayla söndür
  for (int i = 6; i >= 2; i--) {
    digitalWrite(i, LOW);
    delay(500);
  }
}

3. Uygulama: İç İçe Döngülerle Her LED'i 10'ar Kez Yakma

Her bir LED'in kendi içinde 10 defa hızlıca yanıp sönmesi ve ardından sıradaki LED'e geçmesi sağlanmıştır. Uçlardaki çakışmaları önlemek için sınır değerler optimize edilmiştir.

void loop() {
  // İleri Yönlü Tarama (Her biri 10 kez yanıp söner)
  for (int i = 2; i <= 6; i++) {
    for (int c = 0; c < 10; c++) {
      digitalWrite(i, HIGH);
      delay(100);
      digitalWrite(i, LOW);
      delay(100);
    }
  }
  
  // Geri Yönlü Tarama (Sınır ayarlı)
  for (int i = 5; i >= 3; i--) {
    for (int c = 0; c < 10; c++) {
      digitalWrite(i, HIGH);
      delay(100);
      digitalWrite(i, LOW);
      delay(100);
    }
  }
}

Arduino ve Buton Antrenmanı (2. Örnek) - Robo90 #24

Uygulama Amacı ve Devre Mimarisi

Temel C/C++ ve donanım eğitiminin bu aşamasında, butonlar ve anahtarlama devreleri ile ilgili pratikler pekiştirilmektedir. Bu uygulamada buton durumlarına bağlı olarak dijital çıkışların (LED'lerin) mantıksal denetimi gerçekleştirilir.

  • Temel Bileşenler: Push button (itmeli buton), dirençler (pull-up / pull-down), LED'ler ve bağlantı kabloları.
  • Öğrenilen Kazanım: Dijital giriş pinlerinden veri okuma (digitalRead) ve bu verileri karar yapılarıyla (if-else) işleme.

Örnek Kontrol Kodu Yapısı

Butona basılma durumuna göre LED'in durumunu değiştiren temel mantıksal kontrol yapısı:

const int buttonPin = 2; // Butonun bağlı olduğu dijital pin
const int ledPin = 8;    // LED'in bağlı olduğu dijital pin

void setup() {
  pinMode(buttonPin, INPUT); // Buton pini giriş olarak ayarlanır
  pinMode(ledPin, OUTPUT);   // LED pini çıkış olarak ayarlanır
}

void loop() {
  int buttonState = digitalRead(buttonPin); // Buton durumu okunur

  // Butona basıldıysa (örneğin HIGH okunduysa)
  if (buttonState == HIGH) {
    digitalWrite(ledPin, HIGH); // LED'i yak
  } else {
    digitalWrite(ledPin, LOW);  // LED'i söndür
  }
}

Arduino ve Butonlar ile LED Kontrolü (3. Örnek) - Robo90 #25

Devre Kurulumu ve Donanım Detayları

Bu uygulamada algoritma kurma yeteneklerini geliştirmek amacıyla 2 adet buton ve 4 adet farklı renkte LED (Kırmızı, Mavi, Yeşil, Sarı) kullanılmaktadır.

  • LED Pinleri: Sırasıyla dijital 2, 3, 4 ve 5 numaralı pinler.
  • Buton Pinleri: Dijital 8 ve 9 numaralı pinler.
  • Temel Amaç: Buton durumlarına göre anlık tepki (basılı tutulduğu sürece) ve kalıcı durum değiştirme (toggling / aç-kapat mantığı) senaryolarını kodlamak.

1. Senaryo: Butona Basılı Tutulduğunda LED'leri Yakma

İlk butona (Button 1) basıldığı sürece tüm LED'lerin yanması, el çekildiğinde ise sönmesi sağlanmıştır.

const int btn1 = 8;
const int led1 = 2, led2 = 3, led3 = 4, led4 = 5;

void setup() {
  pinMode(btn1, INPUT);
  pinMode(led1, OUTPUT);
  pinMode(led2, OUTPUT);
  pinMode(led3, OUTPUT);
  pinMode(led4, OUTPUT);
}

void loop() {
  if (digitalRead(btn1) == HIGH) {
    // Butona basılıyken tüm LED'leri aç
    digitalWrite(led1, HIGH);
    digitalWrite(2, HIGH); // Örnek olarak doğrudan pinler de yazılabilir
    digitalWrite(3, HIGH);
    digitalWrite(4, HIGH);
  } else {
    // El çekildiğinde tüm LED'leri kapat
    digitalWrite(led1, LOW);
    digitalWrite(2, LOW);
    digitalWrite(3, LOW);
    digitalWrite(4, LOW);
  }
}

2. Senaryo: Bas-Bırak (Toggle) Mantığı ile Kalıcı Kontrol

İkinci butona bir kez basıp el çekildiğinde LED'lerin sürekli yanık kalması, aynı butona tekrar basılıp çekildiğinde ise sönmesi (tıklamalı tükenmez kalem mantığı) sağlanmıştır.

const int btn2 = 9;
int state = 0; // Durum hafızası değişkeni

void loop() {
  if (digitalRead(btn2) == HIGH) {
    state = !state; // State değerini tersine çevir (0 ise 1, 1 ise 0 yap)
    
    // Duruma göre LED'leri sür
    if (state == 1) {
      digitalWrite(2, HIGH); digitalWrite(3, HIGH);
      digitalWrite(4, HIGH); digitalWrite(5, HIGH);
    } else {
      digitalWrite(2, LOW); digitalWrite(3, LOW);
      digitalWrite(4, LOW); digitalWrite(5, LOW);
    }
    
    delay(100); // Kararsızlıkları (bouncing) önlemek için gecikme
    while(digitalRead(btn2) == HIGH); // Butondan el çekilene kadar bekle
  }
}

Arduino ve Potansiyometre ile LED Kontrolü (4. Örnek) - Robo90 #26

Uygulama Amacı ve Devre Kurulumu

Bu uygulamada bir potansiyometre kullanılarak LED'in parlaklığının kontrol edilmesi (dimmer mantığı) işlenmektedir.

  • LED Bağlantısı: PWM destekli dijital pin olan 3 numaralı pin (çıkış).
  • Potansiyometre Bağlantısı: Analog giriş pinlerinden A0 pini. Analog pinler varsayılan olarak giriş (INPUT) modunda çalıştığı için pinMode tanımı gerektirmez.
  • Temel Kazanım: Analog okuma (analogRead - 0 ile 1023 arası değerler) ile PWM çıkış (analogWrite - 0 ile 255 arası değerler) arasındaki veri aralığı uyumsuzluğunu gidermek için map() fonksiyonunun kullanımı.

Örnek Kontrol Kodu Yapısı

Potansiyometreden okunan 0-1023 arasındaki değerlerin map() fonksiyonu yardımıyla 0-255 aralığına ölçeklenerek LED parlaklığını ayarlamakta kullanılmasını sağlayan kod:

const int ledPin = 3;   // PWM özellikli LED pini
const int potPin = A0;  // Potansiyometre analog giriş pini

void setup() {
  pinMode(ledPin, OUTPUT);
  // Not: Analog pinler otomatik input olduğu için pinMode(potPin, INPUT) gerekmez.
}

void loop() {
  // 1. Potansiyometreden 0 - 1023 arasında ham değer oku
  int potValue = analogRead(potPin);
  
  // 2. map() fonksiyonu ile değeri 0 - 255 aralığına ölçekle
  // map(değer, minGirdi, maxGirdi, minÇıktı, maxÇıktı)
  int ledBrightness = map(potValue, 0, 1023, 0, 255);
  
  // 3. Ölçeklenen değeri PWM çıkışı üzerinden LED'e gönder
  analogWrite(ledPin, ledBrightness);
}

Arduino ile LDR Kullanımı (5. Örnek) - Robo90 #27

Uygulama Amacı ve Devre Kurulumu

Bu uygulamada ortamdaki ışık şiddetine göre direnç değiştiren LDR (Light Dependent Resistor - Işığa Bağımlı Direnç / Fotoresistör) bileşeninin kullanımı işlenmektedir. Amaç, LDR'den gelen analog verileri okuyarak aydınlık/karanlık durumlarına göre bir LED'i veya sistemi kontrol etmektir.

  • LDR Bağlantısı: Analog giriş pinlerinden biri (Örn: A0 pini). LDR, analog pin ile besleme gerilimi (5V veya GND) arasında bir sabit dirençle (pull-up/pull-down mantığıyla gerilim bölücü devre) bağlanır.
  • LED Bağlantısı: Dijital pin veya PWM çıkış pini (Örn: 3 numaralı pin).
  • Temel Kazanım: Sensör dinamiklerini anlamak, analog okuma değerlerini eşik (threshold) mantığıyla mantıksal kararlara dönüştürmek.

Örnek Kontrol Kodu Yapısı

Ortam karardığında (LDR değeri belirli bir eşiğin altına düştüğünde) LED'in yanmasını, aydınlandığında ise sönmesini sağlayan temel eşik kontrol kodu:

const int ldrPin = A0;  // LDR'nin bağlı olduğu analog pin
const int ledPin = 3;   // LED'in bağlı olduğu dijital pin
int ldrValue = 0;       // LDR'den okunan değerleri saklamak için değişken
const int threshold = 500; // Karanlık eşik değeri

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);   // Seri haberleşmeyi başlat
}

void loop() {
  // 1. LDR'den analog ışık değerini oku (0 - 1023 arası)
  ldrValue = analogRead(ldrPin);
  
  // Okunan değeri ekrana yazdırarak eşik değerini gözlemle
  Serial.print("LDR Değeri: ");
  Serial.println(ldrValue);
  
  // 2. Ortam ışığına göre karar ver
  if (ldrValue < threshold) {
    // Ortam karanlıksa LED'i yak
    digitalWrite(ledPin, HIGH);
  } else {
    // Ortam aydınlıksa LED'i söndür
    digitalWrite(ledPin, LOW);
  }
  
  delay(100); // Kararlı okuma için kısa bir gecikme
}
