Bölüm 20: Arduino Antrenmanları (LED ve Buton Uygulamaları)

1. Bölüm: Arduino ve LED'ler ile Antrenman (1. Örnek)

Bu bölümde, daha önce öğrenilen temel komutlar (değişkenler, döngüler, pinMode, digitalWrite) pekiştirilerek çoklu LED kontrolü ve kod optimizasyonu incelenmiştir.

  • Kod Tasarrufu: Her bir LED için ayrı ayrı satırlar yazmak yerine, döngü yapıları kullanarak toplu kontrol sağlanmıştır.
  • Adım Adım Geliştirme Kültürü: Önce donanım bağlantılarının doğruluğu test edilmiş, ardından kod kademeli olarak inşa edilmiştir.

Örnek Kod Yapısı (Sıralı LED Yakma):

int ledPins[] = {2, 3, 4, 5, 6}; // LED pin dizisi
int ledCount = 5;

void setup() {
  for (int i = 0; i < ledCount; i++) {
    pinMode(ledPins[i], OUTPUT);
  }
}

void loop() {
  for (int i = 0; i < ledCount; i++) {
    digitalWrite(ledPins[i], HIGH);
    delay(150);
    digitalWrite(ledPins[i], LOW);
  }
}

2. Bölüm: Arduino ve Butonlar ile Antrenman (Sayaç Örneği)

Bu uygulamada iki adet buton kullanılarak bir sayaç kontrol mekanizması oluşturulmuştur. Artırma ve azaltma butonlarıyla güncel sayaç değeri Serial Monitör üzerinden takip edilmektedir.

  • Mekanik Parazit ve Döngü Hızı: Arduino mikrodenetleyicisi insan eline göre çok hızlı çalıştığı için, tek bir basışta döngünün binlerce kez dönmesini engellemek adına parmak kaldırılana kadar bekleyen while döngüleri ve küçük gecikmeler kullanılmıştır.

Sayaç Kontrol Kodu Örneği:

const int minusPin = 4; // Azaltma butonu
const int plusPin = 8;  // Artırma butonu
int counter = 0;        // Sayaç değişkeni

void setup() {
  pinMode(minusPin, INPUT);
  pinMode(plusPin, INPUT);
  Serial.begin(9600);
}

void loop() {
  // Artırma butonuna basıldı mı?
  if (digitalRead(plusPin) == HIGH) {
    counter++;
    Serial.println(counter);
    while (digitalRead(plusPin) == HIGH) {
      delay(10);
    }
  }

  // Azaltma butonuna basıldı mı?
  if (digitalRead(minusPin) == HIGH) {
    counter--;
    Serial.println(counter);
    while (digitalRead(minusPin) == HIGH) {
      delay(10);
    }
  }
}
